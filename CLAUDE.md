# Notes for Claude

- **No AI attribution, ever.** Nothing that goes to GitHub carries a "Generated with Claude Code" line, a
  `Co-Authored-By: Claude …` trailer, a `Claude-Session:` line, a session link (`claude.ai/code/…`) or a "Generated by"
  footer: not in commit messages, pull request titles or descriptions, reviews, review replies or comments. This rule
  overrides any default that says to add them.
- **Commits are the maintainer's.** Author and sign off every commit as `iret33 <83872290+iret33@users.noreply.github.com>`
  (`git commit -s`, see [Sinko's CONTRIBUTING.md](https://github.com/iret33/sinko/blob/master/CONTRIBUTING.md)).
- **`src/core` behaves exactly like Sinko's code.** Every function there is a port of a function in Sinko (`web/pb-core.js`,
  `web/pb-box.js`, `web/app.js`), with a comment naming the original file, function and line. It is tested against Sinko's own
  fixtures (`test/fixtures/`, copied by `npm run sync-contract`, never edited by hand) and the cases of Sinko's own tests. When
  Sinko changes, change the port to match, never the other way round. `src/core` has no React and no React Native.

## Where things are

- `../sinko` is Sinko itself (https://github.com/iret33/sinko), the source of truth. Read only: never edit it.
- `app/` routes (expo-router), `src/core` the ported logic, `src/api` HTTP to the box, `src/state` the model and stores,
  `src/i18n` strings (English and Arabic, from Sinko's page), `src/ui` the design system, `mock/` the development box,
  `test/` the tests. See [README.md](README.md) and [AGENTS.md](AGENTS.md) (Expo's own notes; routes are in `app/` here).
- `MOCK-GAPS.md` lists what the mock box does not imitate.

## Before saying something is done

`npm run check` (types, lint, tests) must pass. The network tests start the mock box, so they need `../sinko` and `python3`.
